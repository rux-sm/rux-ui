Colour-carrying components — the rule 2.15 gallery

Every component in this system that spends a hue, rendered across every hue it can take, with every status mark that can land on it. Rule 2.15 makes co-occurrence the test — a hue may mean several things provided no two of them render in the same element at the same instant — so the question a gallery answers and a swatch grid cannot is which components actually put two meanings in one place. Each card states its function (F1–F5, rule 2.14) and whether a status can co-occur on it. Contrast is measured live in the sRGB branch off tokens.css source.

B backs each mark with a surface-1 disc, so the ink returns to the F3 surface it was measured for and the disc becomes the thing that must clear the fill (3:1, non-text). C keeps the bare glyph and adds a surface-1 ring. D surrenders the status hue and uses the fill's own published label. B and C measure identically — same surface-1 against the same fill — so the numbers cannot separate them and the choice is an eyeball. That is what this page is for.
