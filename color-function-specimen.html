Colour — the function axis

color.md rule 2.2 partitions the vertical axis: ten steps, one purpose each. That governs steps. This page asks the other question — what happens when one role is spent on several functions, each with a different floor and a different thing to clear against. Every number is measured here, in the sRGB branch, per rule 2.11's worse-gamut clause.

■ clears its floor ■ below it F1/F3/F5 → 4.5:1 (text) · F2/F4 → 3:1 (non-text)
D20, and the shape behind it. A cell is red where that role, used for that function, does not clear. The point is not any single number — it is that one row can hold both. A role that is correct as text is not thereby correct as a fill, and nothing in the system currently says so. Inventory: docs/color-consumption-audit.md.
