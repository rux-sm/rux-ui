Tab stripUse data-rux-tabs with role="tablist" for exclusive view switching. The track is recessed; selected items lift above it.
GhostAdd rux-segmented--ghost for low-emphasis view modes. Inactive items stay transparent; the selected item uses the ghost state fill.
PrimaryAdd rux-segmented--primary for an accent-filled active item. Use when the selection needs stronger visual emphasis than the default lifted-surface treatment.

Color mathFilled buttons use OKLCH lightness steps: hover raises lightness, pressed lowers it. Ghost is the exception: transparent base, 10–14% white state fill.
Conflict ruleWhen hover and focus coincide, focus ring persists. Pressed overrides hover background. Disabled wins over all states via pointer-events: none.
