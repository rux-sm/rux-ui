A dark, minimal design system.

Rux is one set of CSS tokens, one component sheet, one naming convention. No build step, no framework. Dark mode only.

Color mathFilled buttons use OKLCH lightness steps: hover raises lightness, pressed lowers it. Ghost is the exception: transparent base, 10–14% white state fill.
Conflict ruleWhen hover and focus coincide, focus ring persists. Pressed overrides hover background. Disabled wins over all states via pointer-events: none.
