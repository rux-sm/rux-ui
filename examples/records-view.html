Archetype · one of three

Records

A table of many things, edited one at a time. The dominant archetype — five of the nine views in this application — and the reference for the four still to be rebuilt.

composition.md §2.3 layout.md §9.4–9.5 shell.md § Workspace tables.md

Usage

Use records when

  • The body holds many of one kind of thing, compared across columns
  • Opening one shows it in a floating window rather than navigating
  • The controls above change what is shown, not what a record is

Use another archetype when

  • The body is a column of settings or prose — document column (§2.4)
  • The body is one continuous surface you navigate within — canvas (§2.5)
  • Neither fits — that is a defect in composition.md, fixed by an amendment there, never by inventing anatomy (§2.1)

The composition

The band holds a “New …” action, search, and a scope with counts — everything that decides what the table shows. The table takes the lg rung because its identity cell is two lines, and its data columns size to content so the identity column absorbs the slack.

Below 720px

Narrow this window past 720px to see it. The row becomes a two-line grid, the header row goes whole rather than column by column, and the four properties .rux-table td publishes are given back. All four rules and their reasons are composition.md §2.3.1 — this page demonstrates them, it does not restate them.

Do and don't

Five, and every one is a defect this repository actually shipped rather than an invented counter-example. Each carries its receipt.

Hiding a column at narrow widths

Do

Hide the header and the cell together, keyed off the same [data-col].

[data-col="phone"] { display: none }

Don't

Hide the cell by a class the header does not carry. Every column to its right shifts one place left of its own header, silently.

Choosing a density rung

Do

Take lg or higher when a cell holds two lines, and let the band pair itself to that rung.

layout.md §9.4

Don't

Stack a name over a secondary line inside the md default. The row runs short of its own content.

Spacing the band

Do

Let the shared toolbar separate its groups, and nest a genuinely flush cluster in one child.

--rux-button-group-gap

Don't

Override the gap in a feature stylesheet. Three views did, under two token names, for the same reason.

shell.md step 6

Framing the table

Do

Let .rux-table-wrap be the only frame. The shell draws none.

Don't

Give a container its own hairline. Two identical borders end up 1px apart.

Accessibility

  • Declare the roles. display: block at narrow widths drops the implicit table/row/cell roles in every engine, so they are written in the markup at every width.
  • The row is a control. It opens the record, so it carries a role and an accessible name — not a bare tabindex — and a real view delegates one listener to <tbody> rather than binding a pair per row on every render.
  • Never state by colour alone. The severity cells say “expired 12 days ago” in words; colour is the second channel, not the only one. Same for the priority indicator, which carries its label as text.
  • Label an icon-only header. aria-label on the <th> — there is no visually-hidden utility in this system, and inventing one to fit a table is what “propose, do not add” exists to stop.
